# 🚀 Layoff Data Analysis with MySQL  

## 📌 Overview  
Ever wondered how layoffs impact different industries, companies, and countries? This project dives deep into a layoff dataset to uncover trends, patterns, and insights using **MySQL**. From cleaning messy data to exploring which industries took the hardest hits, this analysis tells the story behind the numbers.  

## 🎓 What I Learned  
🔹 **SQL Data Cleaning** – Removing duplicates, handling null values, and keeping the dataset crisp and clean.  
🔹 **Data Exploration & Analysis** – Writing SQL queries to track layoffs by company, industry, country, and year.  
🔹 **JSON Import Magic** – Converting CSV files into JSON for seamless database integration.  

## 📂 Files in the Repository  
📌 **`convertcsv.json`** – Converts CSV to JSON format for easy import.  
📌 **`layoffs.csv`** – The raw layoff dataset (before the magic happens).  
📌 **`LayoffsDataCleaning.sql`** – SQL script to clean the dataset (bye-bye duplicates & messy data!).  
📌 **`LayoffsExploratory.sql`** – SQL queries that uncover trends, peak layoff periods, and the biggest industry impacts.  

## 🧹 Data Cleaning Process  
✔ **Removed Duplicates** – No double trouble here!  
✔ **Standardized Data** – Made sure everything followed a consistent format.  
✔ **Handled Missing Values** – No blank spaces left behind.  
✔ **Dropped Unnecessary Columns/Rows** – Keeping only what truly matters.  

## 🛠️ Technologies Used  
- **MySQL** – The powerhouse behind querying, cleaning, and analyzing the data.  
- **JSON Converter** – To make importing data into MySQL more effective.
